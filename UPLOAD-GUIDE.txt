OCTAGON v1.3 측면·거울·안정화 — 폴더 없는 GitHub Pages 업로드용

1. ZIP 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files를 누릅니다.
3. 이 폴더 안의 파일을 전부 선택해 한 번에 올립니다. ZIP 자체는 올리지 않습니다.
4. index.html, app.js, boot.js, config.js, style.css와 카메라 모델 파일이 모두 같은 위치에 있어야 합니다. 파일 이름을 바꾸지 마세요.
5. Commit changes 후 Pages 배포가 완료될 때까지 기다립니다.
6. 자신의 GitHub Pages HTTPS 주소를 Safari에서 직접 엽니다. 기존 저장소라면 https://lilkiis-bot.github.io/virtualsparrig/?v=4 입니다.
7. 카메라를 몸 옆에 두고 옆모습을 촬영하세요. 카메라 연결 버튼을 누르면 권한을 요청합니다. 이미 거절했다면 Safari의 해당 사이트 카메라 설정을 허용으로 바꾸세요.

예전 main.js, arena.js 등의 파일은 남아 있어도 이 배포본 실행에 영향을 주지 않습니다. 새 index.html은 app.js를 실행합니다.

실제 iPad에서 테스트한 결과는 아직 없으며, 데스크톱 WebKit 엔진의 검증은 Safari 실기기 검증을 대신하지 않습니다.
